⚙️ Setup Instructions

1
Get API Keys
Sign up for API keys from:
  • Claude AI: console.anthropic.com
  • DeepSeek: platform.deepseek.com
2
Configure Environment
Update the .env file with your API keys:
CLAUDE_API_KEY=your_key_here DEEPSEEK_API_KEY=your_key_here PORT=3000
3
Install Dependencies
Run the following command:
npm install
4
Start Server
Start the application:
npm start
Then navigate to http://localhost:3000
5
Upload & Analyze
Go to the chart analyzer and upload your trading charts to get instant AI-powered analysis!

📖 How It Works

1. Upload Chart: Select and upload an image of your trading chart.

2. AI Analysis: Your chart is sent to both Claude AI and DeepSeek simultaneously for analysis.

3. Technical Review: Both AI models analyze the chart and identify:

  • Entry Point: The optimal price level to enter a position
  • Stop Loss: Recommended price level to limit losses
  • Take Profit: Target price level for profit realization

4. Results: You receive a combined recommendation plus individual AI analyses for comparison.
